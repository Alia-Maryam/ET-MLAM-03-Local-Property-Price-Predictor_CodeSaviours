# ET-MLAM-03-Local-Property-Price-Predictor_CodeSaviours
This project builds a multiple linear regression model to predict house prices in Faisalabad, Pakistan, using plot size and housing society as inputs. Trained on 50 real Zameen.com listings with a scikit-learn pipeline, it reaches a test R² of 0.734 and an RMSE of about PKR 10 million.
